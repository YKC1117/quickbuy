QuickBuy 1.0 PWA
================

免費手機版，設計給 iPhone / iPad Safari + 加入主畫面使用。

重點：
- 不需要 Apple Developer / TestFlight / Companion
- GitHub Pages 可直接部署
- local-first
- 可離線開啟核心介面
- Platform Catalog / 最近使用 / 我的快捷網站
- 數量 / 規格 / 開賣時間
- 本機備份、加密匯出 / 匯入

iOS 限制：PWA 無法直接讀取或控制另一個 Safari 分頁 DOM，因此 QuickBuy 只負責準備、保存狀態與快速前往。登入、CAPTCHA、OTP、Queue、Payment、Final Confirm 由使用者完成。
