QuickBuy 1.0｜Windows
====================

最簡單安裝：
1. 先把下載的 ZIP 完整解壓縮
2. 雙擊「QuickBuy-安裝精靈.cmd」
3. 依畫面開啟瀏覽器的「開發人員模式」
4. 按「載入未封裝項目」並選 QuickBuy-Extension
5. 把 QuickBuy 釘選到工具列即可使用

完全免費版不需要 額外常駐程式、帳號、付費 API 或背景服務。

為什麼還需要「開發人員模式」？
Chrome / Edge 對商店外的免費擴充功能有限制。若不走付費／商店發布流程，載入未封裝項目是最直接、透明的免費安裝方式。

QuickBuy 可以協助平台辨識、準備數量/規格、倒數、狀態提醒、備份、診斷與安全接力。
登入、CAPTCHA、OTP、Queue、3D Secure、付款與最後確認由使用者完成。
