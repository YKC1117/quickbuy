第一次使用，從這裡開始

這個頁面是給家人、朋友或第一次安裝的人看的。照著 3 個步驟做就可以，不需要理解程式。

Windows Chrome / Edge內建圖像教學安全分享包不保存帳密 / OTP / 付款資料
1

解壓縮整個資料夾

不要只打開 ZIP 裡面的單一檔案。解壓後應該看得到 manifest.json、sidepanel.js、icons 等內容。

2

開啟擴充功能頁

Chrome 請輸入：

chrome://extensions/

Edge 請輸入：

edge://extensions/
3

載入 QuickBuy

開啟「開發人員模式」→「載入未封裝項目」→ 選擇含有 manifest.json 的整個 QuickBuy 資料夾。

成功後點瀏覽器右上角 QuickBuy 圖示，就會開啟側邊欄。

安裝完成後怎麼用？

第一次開啟會看到新手引導，1.0 會自動先做本機安裝體檢，並提供一鍵復原點。朋友傳給你的 QuickBuy 家人分享包，可以直接從新手引導匯入；之後右上角「資料」可隨時做安全備份、復原點、還原與診斷。

✓ 會分享
快捷網站、常用平台排序
✕ 不會分享
帳號、密碼、Cookie、Token、OTP、付款資料、執行中的任務

快速教學

  1. 開啟 Chrome 或 Edge 的擴充功能頁面。
  2. 開啟「開發人員模式」。
  3. 選「載入未封裝項目」，指定 QuickBuy-Extension 資料夾。
  4. 釘選 QuickBuy，開啟側邊欄即可使用。

資料、備份與遇到問題

QuickBuy 右上角「資料」可以做一鍵體檢、安全備份 / 合併還原、家人分享與去識別化診斷。安全備份包含快捷網站與常用平台排序，匯入前會自動建立本機復原點；不匯出姓名、Email、電話、地址、密碼、OTP、Cookie、Token 或付款資料。
